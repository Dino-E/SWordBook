# SWordBook

**Un WordPad para libros.**
SWordBook es un editor de texto sencillo y sin distracciones, diseñado para escribir borradores de novelas, relatos y libros electrónicos.

## Características

- **Archivos DOCX:** crea, edita y guarda documentos compatibles con Word.
- **Estilos de escritura:** aplica estilos para títulos, subtítulos, texto normal, diálogos, pensamientos, citas y separadores de escena.
- **Formato de texto:** personaliza fuentes, colores, alineación, sangrías, interlineado y espaciado.
- **Navegador:** organiza y recorre capítulos y secciones mediante los títulos del documento.
- **Buscar y reemplazar:** encuentra y modifica texto fácilmente.
- **Comentarios:** añade anotaciones al texto seleccionado y adminístralas desde un panel lateral.
- **Copias de seguridad:** ayuda a proteger tu trabajo y recuperar documentos tras un cierre inesperado.
- **Vista continua:** escribe en un espacio de trabajo sin interrupciones entre páginas.
- **Temas:** elige entre los temas Claro, Oscuro y Personalizado.
- **Ajuste de la hoja:** personaliza el tamaño, los márgenes y el color de la hoja sin alterar el contenido del documento.
- **Zoom:** ajusta la escala de visualización para adaptar el espacio de escritura a tus preferencias.

## Atajos de teclado

### Archivos y documentos

| Atajo              | Acción                                          |
| ------------------ | ----------------------------------------------- |
| `Ctrl + N`         | Crear un documento nuevo                        |
| `Ctrl + O`         | Abrir un documento existente (`.docx` o `.txt`) |
| `Ctrl + S`         | Guardar el documento actual                     |
| `Ctrl + Shift + S` | Guardar como, eligiendo otro nombre o ubicación |

### Formato de texto

| Atajo              | Acción                              |
| ------------------ | ----------------------------------- |
| `Ctrl + B`         | Activar o desactivar la negrita     |
| `Ctrl + I`         | Activar o desactivar la cursiva     |
| `Ctrl + U`         | Activar o desactivar el subrayado   |
| `Ctrl + Shift + X` | Activar o desactivar el tachado     |
| `Ctrl + =`         | Activar o desactivar el subíndice   |
| `Ctrl + Shift + =` | Activar o desactivar el superíndice |
| `Ctrl + Shift + >` | Aumentar el tamaño de la fuente     |
| `Ctrl + Shift + <` | Disminuir el tamaño de la fuente    |

### Párrafos y alineación

| Atajo              | Acción                                              |
| ------------------ | --------------------------------------------------- |
| `Ctrl + L`         | Alinear a la izquierda                              |
| `Ctrl + E`         | Centrar el párrafo                                  |
| `Ctrl + R`         | Alinear a la derecha                                |
| `Ctrl + J`         | Justificar el párrafo                               |
| `Ctrl + M`         | Aumentar la sangría izquierda                       |
| `Ctrl + Shift + M` | Reducir la sangría izquierda                        |
| `Ctrl + Shift + N` | Aplicar el estilo base de párrafo (*Body / Cuerpo*) |

### Estilos de escritura

| Atajo                   | Acción                                                                       |
| ----------------------- | ---------------------------------------------------------------------------- |
| `Ctrl + 1` a `Ctrl + 9` | Aplicar uno de los primeros nueve estilos disponibles en la cinta de estilos |

Los estilos concretos dependen de su orden en la cinta de herramientas. Puedes utilizarlos para aplicar rápidamente los formatos de escritura disponibles en tu configuración.

### Búsqueda y navegación

| Atajo            | Acción                                     |
| ---------------- | ------------------------------------------ |
| `Ctrl + F`       | Abrir la ventana de búsqueda               |
| `Ctrl + H`       | Abrir la ventana de búsqueda y reemplazo   |
| `F5`             | Mostrar u ocultar el navegador de títulos  |
| `F6`             | Mostrar u ocultar el panel de comentarios  |
| `Ctrl + Alt + M` | Añadir un comentario al texto seleccionado |

### Zoom

| Atajo                    | Acción                                                      |
| ------------------------ | ----------------------------------------------------------- |
| `Ctrl + rueda del ratón` | Acercar o alejar el zoom de la hoja en incrementos del 10 % |

## Estado del proyecto

**Versión:** alfa (`v0.1.1`).

SWordBook se encuentra en desarrollo. Aunque guarda documentos estándar `.docx`, algunas funciones avanzadas de otros procesadores de texto pueden no ser compatibles. Igual que en cualquier procesador de texto, se recomienda conservar copias de seguridad propias de los documentos importantes.
